Configuring an Object Policy
============================

Procedure
---------

#. Log in to OBS Browser.

#. Click the bucket that stores the desired object. The object list is displayed.

#. Locate the object, click |image1| in the **Operation** column, and click **Simple Policy**. The authorization dialog box is displayed.

#. Click **Create Authorization**.

#. In the **Create Authorization** dialog box, specify the permission and select the IAM users to be authorized.


   .. figure:: /_static/images/en-us_image_0000002540964600.png
      :alt: **Figure 1** Creating an object policy

      **Figure 1** Creating an object policy

#. Click **OK**.

#. In the displayed dialog box, click **Close**.
