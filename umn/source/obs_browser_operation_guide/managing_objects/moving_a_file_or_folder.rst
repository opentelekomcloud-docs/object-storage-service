Moving a File or Folder
=======================

Moving a file or folder is implemented by copying the file or folder to a specified location, and then deleting the original file or folder.

Prerequisites
-------------

You have the permission to read and write the ACL of the object you want to move.

Procedure
---------

#. Log in to OBS Browser.
#. Click the bucket where you want to move a file or folder.
#. Right-click the target file or folder and choose **Move** from the shortcut menu.
#. Select a path to save the file or folder. Right-click the path and choose **Paste** from the shortcut menu.

   .. note::

      -  You can only move a file or folder in the current region.
      -  The source path and target path must be different.
