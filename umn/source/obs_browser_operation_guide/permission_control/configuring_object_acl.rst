Configuring Object ACL
======================

Procedure
---------

#. Log in to OBS Browser.
#. Click the bucket that stores the desired object. The object list is displayed.
#. On the right of the target object, click |image1| and choose **Object ACL**.
#. Specify the ACL permissions as needed and click **OK**.
