Copying a File or Folder
========================

This section describes how to copy a file or folder stored on OBS from the source path to the target path.

Prerequisites
-------------

You must have the permission to read the ACL of the object to be renamed.

Procedure
---------

#. Log in to OBS Browser.
#. Click the bucket from which you want to copy a file or folder.
#. Then, right-click the file or folder and choose **Copy** from the shortcut menu.
#. Select a path to save the file or folder. Right-click the path and choose **Paste** from the shortcut menu.

   .. note::

      -  You can only copy a file or folder in the current region.
      -  The source path and target path must be different.
